## Overview
This repository has my solutions and code exercises from the  **University of Helsinki Python Programming MOOC**. 

Unlike standard video tutorials, this course focuses heavily on rigorous problem-solving, and building clean, functional code from scratch.

---

## Repository Structure
The project files are structured to track my progression through the course curriculum:

*   **Fundamentals:** Variables, conditional statements, and basic input/output.
*   **Control Flow:** Mastering `while` and `for` loops, lists, and debugging programmes.
